A tiny program that writes one line of plain text — the most honest status
page message an AI agent writes while every server is down — to
`/output/entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

It writes the status line to `/output/entry.txt` and prints it to stdout.
